# 明确模型收到的证据引文合同

最新 main 的 Standard 双 Task 真实验收中，需求评审的五处引文均存在于原文，却把整篇文本的根 JSON pointer 与单句 quote 配对，按已有严格合同被拒绝。不是原文不存在，而是生产者没有正确使用完整选中范围的语义。

在独立 worktree 为模型输出 Schema 和检查报告加入同一条说明：根指针选择完整输入；短引文用精确行/字符范围，或省略可选 quote。保持既有校验、业务 Spec、预算和工作流不变。扩展领域测试验证真实子串配根指针仍拒绝，合法字符范围和省略引文仍接受。

合入 main 后只运行领域证据定位及配置工作流 Spec 接纳的定向回归；当前真实数据集在安全检查点恢复，保留旧失败、实际任务合同和原始协议。
