# Harness 工作流执行合同

当前实现目标为 Workflow v5、agent-task/v5、orchestration-task/v1。业务阶段由编排 Agent 通过原生工具操作；core 观察事实并接纳合法命令。

## 身份与执行

Controller 绑定 owner、根实例、确切编排 Agent、控制策略及 Session 后继链。Session 绑定由宿主生成，普通讨论和业务 Step 不自动获得编排权。每次原生工具调用核对真实 worker、Turn、工具锁、根实例及递增 epoch。控制权限与文件写权限独立。

编排会话不继承 owner 的普通讨论代码视图，也不挂载业务工作副本；它通过控制工具派发业务执行。工作副本的实际停止证明与快照保护继续适用于业务 Agent，不能把持续活动的项目经理误算成代码 writer。

创建实例、输入就绪和收到业务回执均不自动派发后继。dispatch 显式登记一个确切节点的执行授权；accept 接纳确切执行的实际产物；complete 接纳整体交付。Tool、Agent、Workflow、Control 共享该合同。子流程只展开待执行成员，由同一根 Controller 决定执行。人类确认与 Agent 接纳分开记录。

## 运行计划

活动实例只引用不可变 PlanRevision。每个执行绑定自己的计划、稳定节点、输入摘要及冻结合同；输入、配置、执行回执和终态均不能由新计划重写。

ChangeSet 先预演并绑定计划代次和影响摘要，再登记应用意图。活动执行需要先 quiesce；停止及外部观察在事务外执行。最终切换计划、失效后继和登记复用在同一项目事务内发生。重启从已登记操作恢复，过期预演或扩大影响集合需要重新预演。

影响包含依赖、端口来源、规则引用、Task DAG、子流程、代码及决定/许可。复用必须保持合同和输入等价，并留下 carry-forward。历史记录保留；已完成根实例通过后继继续。

已展开的 Workflow 调用仅延长 timeout 时，可保留原执行及子调用；预演单列 budget_updates，新的活动计划控制超时，原执行仍指向原合同和来源计划。业务正文、依赖、输入、完成条件或其他预算字段变化仍按正常影响分析处理。默认跨阶段 Task 调用预算为 7200 秒，单步允许范围为 1—86400 秒。

## 跳过与例外

bypass Stage 展开确切成员并重写其后继依赖、输入和规则。缺少必需输入或最终输出时拒绝应用。外部材料封存为 TypedMaterial 并显式绑定，不能伪装成平台执行。评审失败和未运行测试保留原值，waiver 独立引用授权、理由和确切对象。

测试要求、评审独立性、业务顺序及人类门禁可按策略调整；权限、真实调用者、历史不可变性和实际 Git 一致性继续由 core 核验。git.advance 使用绑定当前计划、候选和目标的 ActionPermit，不能从模型文本推导批准或测试通过。

tests.run 的 execution 返回实际 argv、工作目录、unix_ms 起止时间、退出码、分离的 stdout/stderr，以及冻结版本中配方文件的全文与 SHA-256。缺失或非 UTF-8 文件单列 gaps，不制造文件内容。实现节点引用实际 Red，交付其本地 Green 原始记录；固定镜像 Green/verify 由后续平台节点产生，二者分别保留来源。

隔离 Node reporter 保留具体断言诊断、错误消息、堆栈及原因链，并将测试自己的 stdout/stderr 作为数据封装；它们不能伪造顶层分类。仅有错误类别不足以证明 Red 的业务原因。旧回执缺少诊断时，在同一不可变候选、镜像、配方与测试文件上新增诊断复验，保留旧回执和拒绝结论，通过运行计划显式绑定补充证据后再评审。

## 事件与恢复

业务事件进入持久化队列；同根实例仅一个活动编排 Turn。重复事件、工具调用及命令通过稳定键接纳。项目经理派发后可等待，不阻塞原生工具请求；并发为一时让出执行配额。模型不可用、预算耗尽或未知执行结果不会恢复旧自动推进。

精简状态优先显示待决、运行和排队节点，再补充完成历史，不能只截取定义开头。每个节点分别投影确认策略、匹配当前执行/输入/输出的确认引用、豁免引用及 human_satisfied；waiting_confirmation 是等待显式接纳的执行状态，不能据此否认已经落账的确认。确认改变唤醒摘要与进展预算，核心仍等待项目经理通过工具显式接纳。

## 协议与升级

新活动数据仅使用 v5。离线升级先检查锁、活动执行和未知副作用，再备份并按确定性映射转换，保留旧配置、任务、产物及会话事实。跨库升级通过 journal 恢复；运行入口不隐式升级，也不删除数据。
