| U02 安装与登录 | 固定版本原生程序进入用户级内容缓存；跨数据集复用程序，不共享凭据。已有登记或完整缓存可以核验、恢复登记；共享锁、临时目录与原子发布保护半成品。Docker 安装按组合内容和真实镜像身份复用，恢复登记需要 recipe 标签或不可变 OCI 来源证明。 |

| U04 安装归属 | 删除独立运行资源源和页面。Harness 保存唯一程序版本、包、许可证、入口、本机发行件和驱动扩展；Sandbox 保存 Docker 基础镜像、系统包、后端文件及可选预构建镜像映射。内部 ExecutionRecipe 由二者组合，不能独立发布或编辑为配置源。 |
| U05 调度归属 | 删除独立调度策略源及选择器。并发、动作数、租约、技术重试和 Agent 唤醒预算位于 Workflow.scheduling，发布时物化缺省值，进入 Workflow/Standard 摘要与冻结快照。手动/Rust/Agent 使用共同派发边界；子流程保留自身约束。显式调整运行计划时更新对应调度视图。 |
| U06 / A02 讨论 | 增量持续更新同一消息，最终全文替换临时文本；移除事件条数、合并提示和分片入口。正常停止与完成回执不占聊天卡片。每轮回复提供“原始事件”普通新标签页，读取最终非增量记录、执行信息、停止证明和 JSON；可刷新、复制，校验项目/Session/Turn 归属。 |

Harness Profile 的 `policy.platform` 只保存平台操作权限；唤醒预算属于 Workflow。`policy.tool_refs` 是宿主管理工具的确切源引用：省略表示完整能力中的此类工具均可使用，显式空数组表示全部拒绝；原生工具限制仍使用 policy.tools 和实际驱动合同。工具引用进入有类型依赖图并校验作用域，缺失平台权限不回退为允许全部。

原 16 个步骤限制转为专用 Profile：测试只写 tests、实现阶段 tests 只读、文档与评审只读，以及确切工具范围。相同 Agent 的权限锁按工作流和步骤保存，避免共用一份锁。实际挂载从可信工程输入解析；没有工程代码视图的会话只能访问私有目录，普通讨论的代码资料使用独立导出，工程工作树写入仍要求冻结的 Workflow 任务。

冻结 codec 保存确切源与选择，按原引用重建，不增加展开权限或组合配方的权威存储。恢复、重试、子流程和运行计划调整保留原 Sandbox/默认绑定；Host 对正式步骤的补充消息沿用冻结 Profile。权限改绑派生的新路径经核验后进入后继会话，原输入与回执保留。
