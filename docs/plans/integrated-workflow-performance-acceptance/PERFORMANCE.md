## 长流程原生历史与整体效率

- r8的40 Turn原生恢复回复17431291bytes，超过16MiB后失败。同一历史只读副本使用excludeTurns后19730bytes，线程身份和内部完整历史不变。r9实际49次经理恢复全部excludeTurns=true、原线程、0回传Turn，最大脱敏journal回复18909bytes；该值不是未脱敏wire字节。
- 同一r6耐久材料离线薄化，回复总量667283→39408bytes，单条最大97594→1643bytes，只证明相同材料的序列化缩减。
- r8经理41 Turn墙钟累计1831.53秒，330原生往返累计53.57秒，没有workflow_segment；两种时长有不同作用域和重叠，不能相减为纯推理时间。r9已自主采用技术段，证明能力存在，但调度策略及整体效率仍需R8专项设计。
- 真实Feature9失败现场315项原生往返P95/P99=1320.05/2310.24ms，8项拒绝。225项不与本轮辅助构建重叠的样本仍为694.20/1093.96ms。不能只用短轮约100ms替代复杂长流程尾部；其中可定位问题已经修复，最新候选未完成相同长流程，收益不能补写。
