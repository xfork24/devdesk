# 每项目数据库与全局配置库

状态：已实施并验收。本文件在计划/报告目录整理时补录，依据用户原需求与[既有验收报告](project-databases.md)归纳已执行范围，不冒充实施前保存的计划。历史验证平台、结果及限制以该报告为准。

## 需求与范围

将单一 SQLite 模型拆为每项目独立数据库文件，打开项目时切换 active 数据库；单独的全局 SQLite 实例保存全局配置。

## 实施与验收范围

1. 全局库保存共享配置、定义、项目索引和活动项目；项目库仅保存本项目工程状态，产物按项目隔离。
2. `project.open` 切换活动 Engine，重启恢复选择；请求、Artifact 与 SSE 固定项目作用域，过期作用域被拒绝。
3. 已打开项目继续执行，所有项目共享全局并发额度；定义修订不可变，配置更新不改写历史绑定。
4. 旧库先建立一致性副本，再升级并按领域归属拆分；核对行、外键、事件、操作及 Artifact 哈希后发布，保留旧库与文件，失败可重试。
5. 以 Rust 存储/恢复测试、debug/release HTTP、standalone Host 和 Web 项目切换/重载验证上述行为，分别记录实际平台与边界。

设计依据见 [ADR-010](../../design.md#adr-010每项目数据库与全局配置库) 和 [协议](../../protocol.md)。本计划不包含 data 目录搬迁或后续真实适配器接入。
