# 每项目数据库与全局配置库验收

日期：2026-11-08。平台：macOS Apple Silicon。评审性质：实现者自检与自动化验证。

## 实现结果

- `<data>/global.sqlite3` 保存全局并发配置、共享定义、项目索引、活动项目选择及全局配置命令记录。
- `<data>/projects/<project-id>/engineering.sqlite3` 只保存一个项目的工程状态、事件与操作记录；产物位于该项目的 `artifacts/`。
- Web 项目选择调用 `project.open`，后端切换活动 Engine，重启恢复上次选择。请求和 SSE 固定其数据库作用域，过期的项目作用域被拒绝。
- 切换不终止已打开项目的执行；调度继续遵守所有已打开项目共享的全局额度。项目目录分页与当前项目设置分别返回，跨页不改变活动项目。
- 全局定义按不可变修订复制到项目库；新修订可跨项目使用，已有正文、执行锁与历史不会被改写。

## 迁移与故障验证

旧根目录 `engineering.sqlite3` 使用一致性快照复制到临时文件，在副本上执行 schema 升级，再按领域归属拆分。全部工程行、事件、幂等记录和产物必须确定归属；校验产物哈希后，所有项目成功落盘才发布全局目录及布局版本。

自动化用例覆盖：两个旧项目的规划、任务实现、交付、评审、Merge、Snapshot、资源、外部操作和 Artifact；逐表核对迁移前后数量、外键与产物内容；保留原库字节；旧创建命令仍映射到原项目 ID。另验证 v1 副本升级、产物损坏后的失败与重试、路径及符号链接拒绝、创建预留 ID 的重启重试、打开失败保留原活动项目。

根目录旧库、旧产物和 `runtime.json` 不删除、不原地升级。布局成功迁移后只使用新的配置与项目库；再次打开不会重复拆分。此数据库结构升级不等同于尚未实现的 data 目录搬迁。

- Rust **73 项**：66 项适配器/契约/集成测试、3 项领域测试、4 项 host 项目数据库测试。
- debug/release HTTP 检查：鉴权、Host/Origin、中文及空格路径、进程锁、幂等、重启、数据库文件及项目隔离、全局 SQLite 设置、Artifact 作用域、SSE 游标与连接归属。release 同时验证复制到空目录运行的独立程序。
- debug/release 各 **5 项** Chromium Web E2E：完整双 Task 交付闭环、异常恢复、分页与 revision 冲突、清理重试、项目数据库切换与重载。

最后对项目目录分页和异步 Artifact 展示作收尾核对，并重新执行 host 测试、两种构建的 HTTP、完整 Web 闭环和项目切换用例。格式与 diff 检查通过。

## 边界

项目库与全局目录不组成跨库原子事务；Project 设置以项目库为准，目录摘要在重新打开和查询时修正。已打开项目的连接保留到进程退出；重启只自动打开上次活动项目，其他项目在首次打开时执行恢复检查。本轮未引入真实外部适配器，也未改变现有 simulation 执行边界。

设计与协议见 [ADR-010](../design.md#adr-010每项目数据库与全局配置库) 和 [本地协议](../protocol.md)。
