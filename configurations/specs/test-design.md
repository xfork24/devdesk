# Test Design Specification

## 用例与配方

`cases` 将独立行为断言映射到 Task 的 AC。覆盖主要行为及适用异常。 `recipe` 使用冻结的 `independent_runner`，测试文件位于 `tests/`，记录运行所需的配方和时间预算。

## 新接口

`interfaces` 只申报平台为缺失接口预置可加载空函数所需的路径、运行器和导出。保留既有实现，确保导入指向声明接口。

## 判定

有效 Red 来自业务断言对预期行为的失败，语法、装载、依赖和环境故障须单独处理。基线已通过时记录事实及用例。Green 使用原用例验证固定实现版本。
