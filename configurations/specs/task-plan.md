# Task Plan Specification

## 任务声明

使用结构化任务列表。每项必须说明稳定标识 `key`、标题、实施说明、交付范围、直接依赖、依赖理由和验收责任。依赖从真实接口或交付产物推导，空依赖使用空列表。

## 验收责任

用 `condition`、`independent_test`、`regression` 明确每个 AC 的验收和测试责任。行为断言、文档审阅和项目回归各有适用范围。可并行的修改保留独立工作边界，单项任务可以独立验收。

## 接纳检查

任务键唯一，依赖可解析且无环，关键前置关系和验收完整。核对 PRD、设计和当前测试配置；机器 DAG 结构校验和独立内容评审均需通过。
