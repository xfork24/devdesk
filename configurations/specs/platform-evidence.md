# Platform Evidence Specification

## 原始事实与范围

平台证据绑定执行、步骤、操作身份、版本和原始回执。评审及下游交付使用同一份确切产物，来源和状态与实际操作一致。

## Git 与审批

分别记录源发布、目标基线、试合并候选、PR 创建、远端合入和本地同步。审批材料包含 PR、完整差异、源、目标、候选、对应测试与独立评审。真实人类决定绑定这组确切材料；新版本需重新经过适用的门禁。

## 测试与终态

使用随工作冻结的项目测试配置及实际运行环境，为实际代码版本记录配方、命令和测试结果。未配置回归时记录原因并按现有合同接纳该步骤，独立 Red/Green 仍执行。对于已配置的测试，空测试、超时、取消、环境错误、不支持的执行器及未知结果均应保留为各自的真实状态。
