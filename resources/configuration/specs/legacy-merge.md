# 候选与合入规范

## 阶段意图

确保被验证和评审的精确候选，就是最终推进目标分支的内容。

## 输入与前置条件

已接受源交付、精确源 SHA、目标基线、候选构造规则、测试和评审要求。

## 必需交付内容

候选父子与来源关系；目标基线；精确候选 SHA；同候选测试及独立 Review；冲突处理；人工确认；本地 CAS、远端精确 lease 和操作回执。

## 内容与一致性检查

核对候选为规定的单父候选，测试与评审均指向同一 SHA，目标未被并发推进。任何候选重建或基线变化都需重新核实相关验证。

## 完成与拒绝标准

主干推进前等待人工确认。CAS 或 lease 失败应刷新目标并重建候选；远端结果未知先查询事实，不能无依据重试，也不能宣称已合入。

## 工具与证据

当前 Step 引用本 Spec 的精确修订，并提供给执行 Agent 和独立评审。保留材料修订、代码或候选 SHA、命令、环境与真实结果，明确未运行和结果未知的事项。traceability、failure_paths、sections 只承担各自已经实现的有限自动检查，正文要求仍需基于内容和证据评审。
