# Implementation Doc 内容规范

## 目标与范围

当前 Task 的实现及后续交付说明。

## 必需内容

实现阶段说明行为、接口、实现范围和逐增量证据；交付整理阶段补齐使用方式、限制、回归及证据引用。明确同一 Task 的输入版本，未执行范围如实说明。

## 来源与一致性

产物必须对应当前 Project、Feature、Task 和确切步骤轮次。引用输入产物、固定代码版本和规范修订；事实来源与作者说明分别保留，不能以成功文字替代实际回执。不得复制其他任务或过期版本的证据。

## 完成与拒绝标准

- 说明内容覆盖本阶段范围、验收和限制，提供具体材料位置。
- 引用当前真实版本和原始报告，不能把计划或作者自述当执行事实。
- 核对本规范要求的对象、版本、依赖和结果一致；指出具体差异和影响。

缺少必需内容、来源不符或结果未知时明确拒绝或标明限制；未执行不写成通过。结构通过后仍须按当前步骤声明的业务范围评审。
