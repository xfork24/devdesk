# 方案规划交付阶段 Spec

## 阶段意图

确认 PRD、Design、Task Plan、Test Plan 一致且可进入开发。

## 所需能力

架构设计、项目管理和测试设计。Agent 必须引用相应 Skill；执行职责与写范围仍受内核规则约束。

## 必需交付内容

- 所有已采纳文档的精确引用与需求追溯。
- Task 覆盖、依赖和测试配方。
- 错误、失败和跨组件边界。
- 独立方案验证及评审证据。

## 完成与拒绝标准

需求交付已经通过评审，方案材料互相一致；实现尚未开始是正常阶段边界。

## 检查方式

由当前 Step 绑定本 Spec 精确修订，并提供给执行 Agent 与独立评审。Markdown 要求按内容和真实证据评审；现有 traceability、failure_paths、sections 只承担各自已实现的有限自动检查，不代表全文要求已自动验证。
