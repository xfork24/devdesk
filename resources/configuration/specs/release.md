# 候选验证与合入阶段 Spec

## 阶段意图

确保仅将已评审、确认的精确候选推进到当前目标。

## 所需能力

Feature 收尾与候选验证、独立评审。Agent 必须引用相应 Skill；执行职责与写范围仍受内核规则约束。

## 必需交付内容

- 当前目标 base 与冻结 candidate SHA。
- 候选构建/测试及来源引用。
- 独立候选评审结论。
- Feature 主干合入前的人工确认和可恢复推进。

## 完成与拒绝标准

候选或目标变化必须重新验证；拒绝陈旧评审、确认或不明确的推进回执，保留重试与核对事实。

## 检查方式

由当前 Step 绑定本 Spec 精确修订，并提供给执行 Agent 与独立评审。Markdown 要求按内容和真实证据评审；现有 traceability、failure_paths、sections 只承担各自已实现的有限自动检查，不代表全文要求已自动验证。
