# Task Report 内容规范

## 目标与范围

Feature 对所有 Task 子流程交接结果的汇总。

## 必需内容

JSON 数组每个条目为 Task Delivery Report。条目的 task.id 与创建清单一一对应，按冻结展开顺序排列；每个子流程确已完成且没有遗漏、重复或串用。保留原始测试、执行、Diff、评审及发布材料。

## 来源与一致性

产物必须对应当前 Project、Feature、Task 和确切步骤轮次。引用输入产物、固定代码版本和规范修订；事实来源与作者说明分别保留，不能以成功文字替代实际回执。不得复制其他任务或过期版本的证据。

## 完成与拒绝标准

- 成员完整且与真实完成的子流程身份、任务及版本对应。
- 汇总由 Workflow foreach 从已完成子流程输出形成，不由 Agent 拼造完成事实。
- 核对本规范要求的对象、版本、依赖和结果一致；指出具体差异和影响。

缺少必需内容、来源不符或结果未知时明确拒绝或标明限制；未执行不写成通过。结构通过后仍须按当前步骤声明的业务范围评审。
