# Task Delivery Report 内容规范

## 目标与范围

单个 Task 的交接材料与证据。

## 必需内容

inputs 包含 task、workspace、red、green、verify、documentation、evidence、review、candidate、candidate_tests、candidate_review、publication、diff 和 candidate_diff。版本相互对应，引用实际报告与 Diff，不用评审摘要代替原始证据。交接材料就绪与平台完成登记分别记录。

## 来源与一致性

产物必须对应当前 Project、Feature、Task 和确切步骤轮次。引用输入产物、固定代码版本和规范修订；事实来源与作者说明分别保留，不能以成功文字替代实际回执。不得复制其他任务或过期版本的证据。

## 完成与拒绝标准

- 逐项核对必需字段和业务内容，范围与上述用途一致。
- 通过真实平台操作、输入和回执核对项目、Task、版本与来源，不接受自述替代。
- 核对本规范要求的对象、版本、依赖和结果一致；指出具体差异和影响。

缺少必需内容、来源不符或结果未知时明确拒绝或标明限制；未执行不写成通过。结构通过后仍须按当前步骤声明的业务范围评审。
