# Feature 收尾与完整验收阶段 Spec

## 阶段意图

汇合全部必需 Task，验证完整 Feature。

## 所需能力

Feature 收尾与候选验证。Agent 必须引用相应 Skill；执行职责与写范围仍受内核规则约束。

## 必需交付内容

- 固定 Task 集合均已完成且交付被接纳。
- Feature 测试、验收映射和真实证据。
- 完整使用说明及已知限制。
- 失败、恢复、资源和独立评审。

## 完成与拒绝标准

Feature 范围测试通过，材料与当前输入和代码版本一致；单个 Task 通过不能代替完整 Feature 验收。

## 检查方式

由当前 Step 绑定本 Spec 精确修订，并提供给执行 Agent 与独立评审。Markdown 要求按内容和真实证据评审；现有 traceability、failure_paths、sections 只承担各自已实现的有限自动检查，不代表全文要求已自动验证。
