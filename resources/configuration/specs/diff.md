# Diff 内容规范

## 目标与范围

由平台比较两个固定 Git 对象生成的代码差异。

## 必需内容

正文为完整 Git patch；平台来源元数据包含 base_revision、revision、比较范围、操作 ID 和正文摘要。明确测试修改、Red 基线、实现增量、Task 整体和候选比较的范围。包含新增、删除、重命名、模式及二进制变更；空差异如实保留。

## 来源与一致性

产物必须对应当前 Project、Feature、Task 和确切步骤轮次。引用输入产物、固定代码版本和规范修订；事实来源与作者说明分别保留，不能以成功文字替代实际回执。不得复制其他任务或过期版本的证据。

## 完成与拒绝标准

- 内容与指定 base/head 的 Git 比较完全一致，无静默截断；修改范围符合当前任务。
- Diff 仅从真实快照或候选工具回执映射产生；评审与交接引用确切 Diff Artifact。
- 核对本规范要求的对象、版本、依赖和结果一致；指出具体差异和影响。

缺少必需内容、来源不符或结果未知时明确拒绝或标明限制；未执行不写成通过。结构通过后仍须按当前步骤声明的业务范围评审。
