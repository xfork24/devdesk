# 编写 Task 独立测试

仅在冻结的可写测试目录内，为本 Task 的 TestRecipe 和验收编写真实 node:test 行为测试，覆盖正常及非法输入。缺少目标实现时用受控动态导入与 assert.fail 产生断言失败；区分目标缺失与传递依赖缺失、语法错误及运行环境错误。不要创建实现桩或新安装依赖。由协调器运行真实 Red。

## 交付内容与检查依据

按本步骤配置及当前绑定 Skill、Spec 的实际内容要求交付，说明具体范围、来源、结果与局限。不能只列出章节标题或声称检查通过。模型校验及独立评审会依据本阶段边界检查这些内容，并保留人类的最终 Approve。结构化字段遵循当前 output_contract；不要把提案、正式交付检查报告和执行摘要混为同一种输出。
