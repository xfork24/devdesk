# TDD 实现与工程说明

## 意图

在有效 Red 后实现冻结 Task 的最小正确行为，保留独立测试。

## 交付物

实现代码、使用说明及验证证据。正文采用 Markdown；协议要求的 ID、验收与 Task 数据保留在对应结构化提案字段中。

## 工作方法

implement 仅写授权 Task 文件，不改独立测试或其他 worktree。docs 节点只读检查代码，返回 Markdown 文档提案，不声称未发生的测试通过。

## 内容检查

- 冻结需求、设计与当前 Task 范围。
- 接口与验收映射。
- 最小实现及错误/失败处理。
- 独立测试保持完整。
- Green 与 verify 的真实结果引用。
- Markdown 使用说明、限制和恢复方法。

## 工具与证据

使用所选 Harness 的原生文件读取、搜索及获准命令工具；历史 AgentID 经验由应用按 Feature/Task 问题检索、选择和恢复后作为上下文提供；不通过 Tool 自行检索。Tool 存在不授予写权限，执行以冻结 Permission 和节点范围为准。标注真实来源与未验证项，不把推测写成事实。
