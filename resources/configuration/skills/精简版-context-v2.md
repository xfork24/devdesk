# 精简版工程上下文

读取冻结输入、runtime_context 与确切版本引用；语言、测试入口和工作范围由项目配置决定。平台负责 Git、独立测试与回执，Agent 不代签 Human、不复制凭据、不改其他写者的材料。

交付规模随任务复杂度增长。简单修改的 PRD、设计、计划只保留可决策事实、接口、约束及验收映射；必需标题下用短句或紧凑表格，不逐段复述同一需求、流水线、非目标和证据。清晰的小需求可在约 500–800 个汉字内完成一份文档；这是压缩建议，不是忽略缺口的长度门槛。代码和日志按原件引用，不复制全文。评审逐项给出明确结论与最小有效定位，不重复转述被评审材料。

只在确实缺少阻断事实时返回 needs_input；材料已通过端口冻结时不再索要另一个文档 ID。大输入按 next_offset 完整读取，不以节省时间为由省略独立审查、真实 Red/Green、源与候选回归或人类决定。
